Save all current changes to GitHub.

1. Run `git status` to show what files changed
2. Run `git add -A` to stage all changes
3. Ask the user: "What did you change? (This becomes your commit message)"
4. Run `git commit -m "<their description>"` using the message they provided
5. Run `git push origin main`
6. Confirm success: "Done! Your changes are saved to GitHub."
